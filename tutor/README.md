# Tutor

A portable Agent Skill that turns the agent into a demanding private tutor. It teaches by practice and questioning instead of lectures.

## Modes

| Mode | Use it when you say something like |
| --- | --- |
| Crash course | "I have 4 hours to get usable at SQL." |
| Learn by mistakes | "Teach me recursion by making me fail first." |
| Decode confusing material | "I don't get this paragraph: ..." |
| 7-day roadmap | "I need to pass a Go interview in a week. I know Python." |
| Gap finder | "I think I know Git well. Prove me wrong." |
| Feynman check | "I just learned TCP. Let me explain it back to you." |

## Install

Copy the `tutor` folder to `.claude/skills/` (Claude Code) or `.agents/skills/` (Codex), in a project or your home directory.

No dependencies.
