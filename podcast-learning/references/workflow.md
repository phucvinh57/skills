# Acquisition and processing

## Media and transcripts

Use argument arrays when invoking subprocesses; quote shell paths and URLs. Never interpolate episode titles or transcript text into shell commands. The commands below use illustrative paths; substitute actual resolved paths safely.

For one YouTube episode (no playlists), download at up to 720p to limit storage:

```sh
yt-dlp --no-playlist -f 'bv*[height<=720]+ba/b[height<=720]/b' --merge-output-format mp4 --write-info-json --write-subs --write-auto-subs --sub-langs 'en,en-orig,en-US,en-GB' --sub-format vtt -o 'podcast-study/VIDEO_ID/source.%(ext)s' -- 'YOUTUBE_URL'
```

Choose one usable English caption track, preferring human captions as identified in metadata. Download failures may need updated yt-dlp or its supported JavaScript runtime; report the error rather than promising all URLs work. Do not automatically use account cookies. MKV or WebM input is also supported; the rendered clips are MP4.

For installed local Whisper:

```sh
whisper /absolute/path/source.mp4 --language en --task transcribe --model base.en --output_format json --output_dir /absolute/path/transcription
```

The first Whisper run may download model weights. Explain that requirement if network access is needed. Larger installed English models may improve specialist terminology. For long episodes, local transcription and rendering can take substantial time. Preserve checkpoints and report progress.

Normalize VTT, SRT, Whisper JSON (`segments` array), or normalized JSON (list of `{start, end, text}` cues):

```sh
python3 /path/to/skill/scripts/podcast.py normalize /path/captions.vtt /path/output/transcript.json
ffprobe -v error -show_entries format=duration -of json /path/source.mp4
```

All JSON timestamps use numeric seconds. Normalization removes overlapping repeated rolling-caption text; inspect the result for unusual caption styles. It does not repair recognition errors. Source JSON and original captions should remain available.

## Manifest interface

Create the manifest in the output directory. Paths are relative to the manifest directory, or absolute. Use this minimum shape, replacing all example values with observed data:

```json
{
  "version": 1,
  "source": {"path": "source.mp4", "url": "https://www.youtube.com/watch?v=VIDEO_ID", "duration": 2400},
  "transcript": {"path": "transcript.json", "provenance": "human English captions"},
  "settings": {"level": "B1–B2", "language": "English", "terms_per_clip": [20, 25], "examples_per_term": 2},
  "clips": [
    {"id": "001", "title": "First topic", "start": 0, "end": 1200, "lesson_status": "pending"},
    {"id": "002", "title": "Second topic", "start": 1200, "end": 2400, "lesson_status": "pending"}
  ]
}
```

IDs must be three decimal digits and unique. Output paths are deterministic: `clips/001/video.mp4`, `subtitles.srt`, `transcript.md`, `lesson.md`. The render command adds `artifacts` and `media_status` per clip and `media_status` at episode level. The agent adds lessons, index, and final episode `status`; these are not generated by the media helper. Helpers do not call an LLM.

```sh
python3 /path/to/skill/scripts/podcast.py validate /path/output/manifest.json
python3 /path/to/skill/scripts/podcast.py render /path/output/manifest.json
```

Validation checks the complete boundary plan. Rendering also probes the real source duration and validates each resulting video. Caption text spanning a cut is included on both sides with timestamps clipped to the local clip interval; this preserves speech context without overlapping video time. Transcript headings display original and clip-relative times.

## Recovery

Completed clips have a completion receipt tied to source identity (path, size, modification time), transcript contents, boundaries, and encoding settings. Existing videos without a matching receipt are never silently replaced: move them aside or use a fresh output directory. After an interrupted render, only a temporary `video.partial.mp4` may be replaced automatically. Regenerate subtitles and transcripts from normalized cues when resuming. Do not change source timestamps after writing lessons without reviewing those lessons again. Do not delete downloads automatically.

Missing transcript: media can be inspected, but topic-aware splitting and source-grounded vocabulary must wait. Missing FFmpeg: prepare the transcript, clip plan, and lessons if possible, clearly label rendering pending, and give dependency instructions. Avoid claiming full completion.
